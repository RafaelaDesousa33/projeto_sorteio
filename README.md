# Projeto Sorteio

Aplicação web para realizar sorteios de forma simples e interativa.

## Tecnologias

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Inserção de participantes
* Sorteio aleatório
* Exibição do resultado na interface

## Objetivo

Projeto desenvolvido para praticar lógica de programação, manipulação do DOM e criação de interfaces web interativas.
